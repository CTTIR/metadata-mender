# Metadata Mender maintenance audit — 2026-11-03

Baseline: public main `a4ad7a9286c5433bc91bdd958bb14c8a339cfb3c` (0.6.1),
including the prior Zotero safety maintenance and current branding. The original
checkout was clean, preserved, and left unchanged; work used an isolated checkout
and frozen baseline. Candidate: **0.6.2**. This is a source/build qualification,
not a GitHub release, Zenodo deposit or production-library acceptance record.

## Strategy and acceptance criteria

1. **Preserve bibliographic evidence.** No conflicting stable identifier or
   following review text may disappear in fill mode; changes record their actual
   source. Complete in source and focused regressions.
2. **Keep batch lifetime and mutation aligned.** Progress errors must stop pending
   writes, keep overlapping batches excluded until all workers settle, and remove
   listeners on every exit. Complete in source and controlled delayed-worker tests.
3. **Keep provider metrics attributable.** Check the requested venue identity,
   refresh cached venue evidence each UTC day, and refuse unusable numbers. Retain
   explicit provider identifiers and collective authors. Complete in source,
   synthetic regressions and bounded public-response parsing.
4. **Produce a reviewable installer.** Rebuild deterministically, retain previous
   artifacts, refuse source symlinks/nested output, and verify source bytes plus the
   advertised checksum. Complete locally. Publication remains a separate gate.
5. **Qualify first use honestly.** Execute documented build commands, inspect the
   rendered guide, and distinguish data-model stubs, native host checks and actual
   external responses. Final host/site observations are recorded below.

Broader personal-name parsing, new providers, a per-field preview UI and wider
Zotero versions remain outside this increment.

## First use and remaining limits

With Node.js 24+ and Python 3.9+, from the candidate repository root:

```sh
node --test tests/*.test.js
python3 -m unittest discover -s tests -p 'test_*.py' -v
./build.sh
python3 tools/build.py --check metadata-mender-0.6.2.xpi
```

Install that local XPI into a separate test profile using Tools → Plugins →
Install Plugin From File. Begin with a disposable regular item, Fill empty fields
only, full author names and title discovery off. Review the resulting metadata
and Extra before enabling overwrite for real work. Existing user choices survive
upgrades.

A provider identifier match does not validate the local reference itself; title
and author conflicts remain review outcomes. Personal-name parsing remains
heuristic, including suffixes and multilingual name order. Explicit PubMed group
names are preserved without guessing personal-name structure. Citation count and
mean citedness are distinct metrics; no journal impact factor is inferred.

The historical 0.1.0 citation/DOI metadata is preserved as archival provenance and
does not establish a release of 0.6.2. Git publication, release creation, hosted
updates and real-library acceptance are separate observations.
